# Análisis del comportamiento de usuarios

## Descripción del proyecto

Este proyecto analiza el comportamiento de uso de los usuarios de un servicio de telecomunicaciones, con el objetivo de identificar patrones relacionados con el consumo de llamadas y mensajes y comparar el comportamiento entre los diferentes planes disponibles.

A través de Python y herramientas de análisis de datos como Pandas, Matplotlib y Seaborn, se realizó un proceso de limpieza, transformación y exploración de los datos. Se integraron diferentes fuentes de información para construir un perfil de uso por usuario, incluyendo variables como edad, ciudad, plan contratado, cantidad de llamadas, cantidad de mensajes y minutos de llamada.

El análisis incluye estadística descriptiva, visualizaciones mediante histogramas y boxplots, identificación de posibles valores atípicos mediante el método del IQR y clasificación de los usuarios en grupos de bajo, medio y alto uso.

El proyecto busca transformar los datos individuales de los usuarios en información útil para comprender sus patrones de comportamiento y facilitar el análisis posterior de las diferencias entre los planes.
